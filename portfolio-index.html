Full penetration test on Metasploitable 2 in an isolated Kali Linux lab. Identified vsftpd 2.3.4 backdoor, UnrealIRCd RCE path, and credential weaknesses via Nmap NSE scripts. Formal risk report + public YouTube presentation.

Python app controlling an L293 H-bridge motor via LabJack UE9 over Ethernet. Forward/reverse, emergency stop, debounced reset detection, and user-gated resume logic — all in clean, maintainable control flow.
